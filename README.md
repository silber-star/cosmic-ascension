# Cosmic Ascension

A science-based browser game: grow from a grain of dust into a star, a black hole and a binary merger. Korean and English.

## Play

Open `index.html` in a browser. There is nothing to install: it is plain JavaScript with no build step.

## Tests and build

- Tests: run `tests/run.js` with JavaScriptCore (`jsc`), or open `tests/index.html` in a browser.
- Build: `python3 build.py` runs the tests, then writes `dist/`, `cosmic-ascension.zip` and a single-file `cosmic-ascension.html`.

The simplifications made to the science are listed in `SCIENCE.md`.
